# HomeAurelia Icons (v1 Shared Core)

This is the **single shared HomeAurelia Core icon pack for v1**.

Shared by:
- Aurelia Edition
- Arcwyre Edition
- Thundergod Edition
- Native Edition

Native note:
Native is also the long-term foundation for the future standalone Home Aurelia Native OS track.

v1 scope:
- One shared core icon set
- 22 canonical category icons
- Freedesktop/KDE compatibility naming and placements
- PNG exports at 16/22/24/32/48/64/128/256/512 + scalable SVG

Edition-specific icon variants are planned for a later phase and are not included in this v1 core pack.
