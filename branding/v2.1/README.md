# PhoenixCore Ecosystem Brand System V2.1

V2.1 elevates the technically clean V2 ecosystem into a richer cinematic application family while preserving a distinct silhouette and operational role for every product.

## Source of truth

- `PRODUCTS.json` locks application names, roles, color law, motif, and environmental scene.
- `scripts/branding/generate_brand_v21.py` deterministically builds SVG icon and wallpaper masters.
- `.github/workflows/brand-v21-qa.yml` generates, renders, audits, and packages the review artifact.

## Product coverage

- PhoenixCore Mobile
- PhoenixCore Desktop
- Phoenix USB Creator
- Device Diagnosis Engine
- Repair Planning Engine
- OS Compatibility Engine
- Boot Media Builder
- Repair Session Manager
- Device Identity Service
- Technician Workspace
- Installer and Deployment Manager
- Recovery Vault

## Visual elevation rules

- one distinct silhouette per application
- shared navy, Phoenix blue, cyan, and steel structural family
- one controlled product accent per role
- layered material gradients and dimensional framing
- environmental wallpapers rather than oversized icon plates
- no embedded raster images
- no baked labels, filenames, screenshots, or checkerboards
- green remains a success state, not the permanent PhoenixCore Mobile identity
- orange remains media creation and deployment language
- Repair Planning remains navy/route-blue/decision-amber

Generated masters are review candidates. V2 remains the fallback until the V2.1 artifact is visually approved.
