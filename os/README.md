# Phoenix OS

`os/` is the future home for Phoenix OS image, installer, package, and branding work.

Phoenix OS is the daily-driver operating system target for Phoenix Platform, not only a recovery environment.

Canonical direction:

- Debian/Ubuntu base.
- KDE Plasma desktop target.
- Wayland-first.
- Browser, Flatpak app store, creator, streaming, gaming, productivity, Bluetooth, Wi-Fi, and printer readiness.
- Recovery superpowers through BootForge, Phoenix Key, Phoenix Agent, and Rust safety gates.

No OS build implementation is added in PR 3.
