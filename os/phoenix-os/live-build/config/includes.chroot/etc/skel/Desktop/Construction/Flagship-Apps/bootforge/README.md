# BootForge

BootForge is the Phoenix deployment, imaging, USB creation, and repair layer.

Future responsibilities:

- Create and validate bootable USB media.
- Prepare Phoenix OS installation and recovery media.
- Drive disk repair, imaging, diagnostics, BootCamp, and OCLP workflows.
- Expose safe workflows through Phoenix Control Center and Phoenix Agent.

The active BootForge/PyQt source remains in `desktop/`. Reference source remains in `legacy/bootable_usb/BootForge/`.

No source is migrated here in PR 3.
