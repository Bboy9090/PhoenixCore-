# Phoenix Key

Phoenix Key is the future rescue and provisioning mode for Phoenix OS.

Future responsibilities:

- Provide trusted rescue entrypoints.
- Run diagnostics and recovery workflows from known-good media.
- Provision Phoenix OS systems and field-repair kits.
- Integrate with BootForge media creation and Phoenix Agent safety checks.

Phoenix Key is a product mode, not a separate operating-system direction.
