# BWOS ISO Build Domain

This directory is the future home of the Bobby’s Worldwide OS distribution and imaging tools.

## Planned Structure
- `builder/`: Python/Shell scripts for assembling editions.
- `live-build/`: Debian-based live image configurations.
- `profiles/`: Edition-specific build targets and overrides.

*Current build logic remains in os/phoenix-os until Phase 2B migration completes.*
