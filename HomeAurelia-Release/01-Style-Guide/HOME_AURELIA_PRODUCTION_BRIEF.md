# HOME AURELIA — FULL PRODUCTION BRIEF

## 0. Purpose

This document defines the full production blueprint for the **Home Aurelia Linux Theme Pack**. It is meant to guide image-generation AI, UI designers, Linux theme builders, KDE themers, icon designers, sound designers, and packaging tools so nobody has to guess what the final system should look like.

The goal is to turn the current Home Aurelia visual concept into a complete installable Linux/KDE identity package including wallpapers, splash screens, Plymouth boot screens, KDE shell theme, icon set, cursors, SDDM login screen, GRUB boot theme, lock screen, sound theme, documentation, install scripts, and future distro branding.

This is not just a wallpaper pack. This is a full operating system identity.

---

# 1. Brand Overview

## Brand Name

**Home Aurelia**

## Main Tagline

**Four Legacies. One Throne.**

## Secondary Taglines

* **Storm. Legacy. Eternity.**
* **One Bloodline. Endless Legends.**
* **Built for Power. Designed for Eternity.**
* **Ascend. Unite. Reign.**
* **Born of storm. Crowned by legacy.**

## Brand Identity

Home Aurelia is a mythic Linux/KDE theme family built around four phoenix legacies. Each legacy represents a different form of power, spirit, and visual energy:

1. **Aurelia** — royal origin, noble skyborn protector.
2. **Arcwyre** — stormforged rebellion, untamed electric fury.
3. **Thundergod** — divine stormbringer, justice and celestial lightning.
4. **Native** — ancestral ascension, ultimate legendary god-form.

The system should feel like a premium fantasy-tech operating system. It should look powerful, sacred, clean, and alive. The design should combine mythic phoenix imagery, KDE/Linux practicality, dark storm UI, royal gold detail, electric blue energy, crimson ascension effects, and polished modern interface design.

* White should be used for readability and divine highlights.
* Backgrounds should remain dark so lightning, icons, and gold trim can breathe.

```ini
ScriptFile=/usr/share/plymouth/themes/home-aurelia/home-aurelia.script
```

## Plymouth Script Goals

The script should:

* detect screen size
* center the splash image
* center logo
* animate a progress bar
* scale safely
* avoid layout breaking on 16:9, 16:10, and ultrawide
