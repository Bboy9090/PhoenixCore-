# BWOS Core Domain

This directory is the future home of the Bobby’s Worldwide OS Core components.

## Planned Structure
- `agent/`: Rust-based hardware execution agent.
- `control-center/`: Consolidated UI (React/Tauri).
- `bootforge/`: Core imaging and recovery primitives.
- `shared/`: Cross-platform Rust crates.

*Current code remains in legacy paths (apps/, crates/, src/) until Phase 2B migration completes.*
