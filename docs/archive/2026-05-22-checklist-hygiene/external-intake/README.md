# External Artifact Intake

This directory contains un-merged artifacts from external AI contributors (Claude, Manus). 

## ⚠️ Safety Warning
These files are for **reference only**. Do not execute any scripts in this directory directly on the host. These files are untrusted until they undergo a formal audit and are harvested into the active source via the **Truth-First** pipeline.

## Contents
- `claude-phoenix-os-foundation/`: Core OS build foundation, themes, and Debian package structures.
- `manus-universal-bootable-usb/`: Comprehensive desktop/mobile ecosystem integration, Rust Tauri backend, and React dashboards.
