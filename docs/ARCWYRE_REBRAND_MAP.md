# ARCWYRE Rebrand Map

This document tracks the mapping of the legacy "Phoenix" codenames to the new public "ARCWYRE" brand.

| Legacy Name | New Brand Name | Context |
| :--- | :--- | :--- |
| **Phoenix OS** | **ARCWYRE OS** | Public Ecosystem Name |
| **Phoenix OS Desktop** | **ARCWYRE OS Desktop** | Linux-based Shipping OS |
