# Native App Exclusivity Model

This document establishes the official product rules, licensing parameters, and deployment rules separating **Blue Phoenix Desktop (Linux Bridge)** from **Blue Phoenix Native (Sovereign Throne)**.

---

## 🚫 The Exclusivity Doctrine

Bobby's World first-party applications and exclusive games are subject to a strict deployment structure. This prevents visual copy-paste loops and establishes a solid value proposition for the sovereign operating system:

```text
  ┌─────────────────────────────────────────────────────────────────┐
  │                   BLUE PHOENIX DESKTOP (Linux)                  │
  │  - Renders "Previews", "Companion", or "Bridge" versions.      │
  │  - Useful for public testing, technician work, and telemetry.   │
  │  - Strictly prohibited from running complete Crown bundles.     │
  └────────────────────────────────┬────────────────────────────────┘
                                   │
                                   ▼
  ┌─────────────────────────────────────────────────────────────────┐
  │                  BLUE PHOENIX NATIVE (No Linux)                 │
  │  - Renders the complete, unrestricted Crown Application Bundle. │
  │  - Runs the full exclusive Crown Game Suite.                     │
  │  - Provides the complete, uncompromised platform vision.         │
  └─────────────────────────────────────────────────────────────────┘
```

---

## ⚖️ Shipped Registry Rules

### 1. The Crown Rule:
> **Flagship Bobby’s World apps and games ship complete only on Blue Phoenix Native OS.**
* If an application is run on a Linux-based environment (Desktop or legacy bridge environment), it must adapt to a "Preview" or "Bridge" profile (e.g. read-only capabilities, simulated pipelines, or companion tools).
* Unrestricted write capabilities, complex self-discovery modules, premium DAW suites, and advanced 3D game engines are unlocked **only** when running inside the sovereign Native shell.

### 2. The Desktop Bridge Rule:
> **Blue Phoenix Desktop may include preview, bridge, or companion versions of selected apps, but the complete flagship suite belongs to Native.**
* Desktop acts as our gateway, creating the developer ecosystem, proving the UX shell layouts (Citadel), and compiling portable logic cores without pretending to run sovereign code natively.
