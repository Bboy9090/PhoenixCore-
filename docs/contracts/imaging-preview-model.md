# Imaging Preview & Safety Model

## 1. The "Preview-First" Constraint
No physical disk I/O may occur until a `Preview Manifest` has been generated and acknowledged by the Phoenix Agent safety engine.

### Preview Manifest Requirements:
*   **Source ID**: Unique ID or Hash of the source image/recipe.
*   **Target Physical ID**: Unique hardware ID of the destination disk (e.g., Serial Number).
*   **Destructive Map**: Explicit list of partitions to be deleted, resized, or formatted.
*   **Estimated Impact**: Total bytes to be written and estimated power consumption.

## 2. Core Protections

### Removable-Only Default
*   Targeting defaults to `USB_REMOVABLE` or `SD_REMOVABLE`.
*   Internal disks are filtered out from selection unless the `ALLOW_INTERNAL_TARGETS` capability is active.

### System Disk Lockout
*   The `System Disk` (containing the running OS) is strictly locked.
*   Formatting the System Disk requires the Agent to be in `RECOVERY_MODE` or `PE_MODE`.
*   A physical "Device Identity Check" (Physical button press or unique token) is mandatory.

### Checksum Validation
*   All images must have a signed `.sha256` manifest.
*   The Agent verifies the image integrity *before* starting the imaging process.
*   Block-level verification is performed periodically during long operations.

## 3. Override Requirements
Dangerous operations (writing to internal disks or system partitions) require:
1.  **Admin/Owner Role**: Validated session.
2.  **Explicit Override Token**: A one-time token generated by the Agent after a successful `Safety Evaluation`.
3.  **Audit Acknowledgment**: User must check a specific "I understand this is destructive" gate in the UI.

## 4. Rollback & Reporting
*   **Success Report**: Includes final checksums, total write time, and target health metrics.
*   **Failure Report**: Captures the exact block failure, error code from the Rust imaging crate, and any successful partial state.
*   **Rollback Policy**: Imaging operations are generally one-way. Safety gates must ensure target health *before* commit to minimize bricking risks.
