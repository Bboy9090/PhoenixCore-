# Native Game Bundle Spec

This document details the official, exclusive **First-Party Games Suite** shipped natively and exclusively inside **Blue Phoenix Native: Crown Edition**.

---

## 🎮 The Exclusive Games Roster

Games are a critical pillar of the sovereign **Blue Phoenix Native** platform identity—proving high-performance native rendering pipelines, low-latency audio mixing, and unified input handling without depending on massive third-party Linux game wrappers.

The frozen first-party games suite contains exactly nine exclusive titles:

### 1. Kai-Jax: Memory Hero
* **Genre:** Action Strategy / Procedural Animation.
* **Sovereign Scope:** Full-fidelity procedural mobile-first combat animations and touch-sensitive HUD inputs.
* **Platform Value:** Demonstrates rapid, real-time bone retargeting and high-performance WebGL/Native vector renders.

### 2. Thunder Runner
* **Genre:** High-speed 2D Platformer.
* **Sovereign Scope:** Kinetic side-scrolling physics engine with responsive, low-latency audio soundtracks.
* **Platform Value:** Core audio-buffer testing and precision frame timing verification.

### 3. Storm Grid
* **Genre:** Puzzle Strategy.
* **Sovereign Scope:** Grid-based logic layers with particle effects and custom glowing neon theme shaders.
* **Platform Value:** UI grid performance scaling and vector particle physics validation.

### 4. Secret Rooms
* **Genre:** 3D Mystery Escape.
* **Sovereign Scope:** Statically baked lighting, 3D spatial sound routing, and perspective camera projection.
* **Platform Value:** 3D graphics pipeline compliance and low-level asset parsing verification.

### 5. Arc Racer
* **Genre:** Retro Vector Racing.
* **Sovereign Scope:** Neo-neon wireframe vector roads scaling with speed and collision geometry hooks.
* **Platform Value:** High-frequency input polling loop and dynamic rendering refresh test bed.
