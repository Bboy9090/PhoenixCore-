# Native Crown Application Bundle

This document catalogs and outlines the core requirements for the flagship **Crown Application Bundle** shipped inside **Blue Phoenix Native: Crown Edition**.

---

## ❄️ Frozen Flagship Bundle Registry

The full, unrestricted execution pathways for these applications belong exclusively to **Blue Phoenix Native**:

### 1. Command (System Console)
* **Sovereign Scope:** Full native system terminal and core configuration manager.
* **Exclusivity:** Direct device-node manipulation and unrestricted raw command console.
* **Desktop Version:** `Command Preview` (sandboxed console emulator with restricted terminal commands).

### 2. Market (Platform Hub)
* **Sovereign Scope:** First-party application directory, secure payments, and billing dashboard.
* **Exclusivity:** Core store with active licensing, updates installation, and native user registries.
* **Desktop Version:** `Market Preview` (read-only software listings mock panel).

### 3. Harbor (File/Network Manager)
* **Sovereign Scope:** Dynamic package center and secure local repository browser.
* **Exclusivity:** Direct interface for package verification, cryptographic signing, and updates downloads.
* **Desktop Version:** `Harbor` (staged custom web views to public repository branches).

### 4. Compass (Technician Suite)
* **Sovereign Scope:** High-integrity file explorer and disk geometries auditor.
* **Exclusivity:** Complete access to physical sector partitions and secure system file directories.
* **Desktop Version:** `Compass` (standard Dolphin file explorer).

### 5. Safe (Security Control)
* **Sovereign Scope:** Cryptographic vault manager, Polkit access dashboard, and permissions panel.
* **Exclusivity:** Low-level configuration of secure heartbeats and dynamic Polkit rules.
* **Desktop Version:** `Safe` (standard KDE System Settings console).

### 6. Workshop (Diagnostics)
* **Sovereign Scope:** Complete hardware analysis, sector diagnostic, and live sensor suite.
* **Exclusivity:** Unrestricted access to raw system telemetry, fan speed maps, and SMART indicators.
* **Desktop Version:** `Workshop Preview` (read-only hardware metrics dashboard).

### 7. BootForge (Media Builder)
* **Sovereign Scope:** Master UEFI/GPT partition builder and boot-media dynamic compiler.
* **Exclusivity:** Direct disk block writes for dynamic sector bootloader generation.
* **Desktop Version:** `BootForge` (dry-run, simulated flash layout preview).

## 🏗️ The MVP Native Bundle

To ensure engineering feasibility and maintain complete truthfulness, the first bootable release of Blue Phoenix Native targets a highly focused, highly polished **MVP App Bundle**:

```text
├── [System Core]
│   ├── Command (Terminal console manager)
│   ├── Harbor (File/package manager)
│   └── BootForge (Bootloader installer helper)
│
├── [Productivity / Insight]
│   ├── Ghost Writer (Minimalist focused text editor)
│   ├── Soul Codex (Self-discovery dashboard)
│   └── Sonic Codex (Digital audio workstation)
│
└── [Utilities / Store]
    ├── Market (Sovereign store indexer)
    └── Workshop (Diagnostics telemetry scanner)
```
