# ARCWYRE Brand Identity

**Tagline:** Boot the broken. Rewire the future.

## 1. Core Philosophy
ARCWYRE is a **repair-first, recovery-first** platform. It is designed for the moment when a machine fails and the user must reclaim control. The aesthetic is industrial, electric, and resilient.

## 2. Visual Palette: "The Forged Storm"
The brand uses a high-contrast, atmospheric palette inspired by industrial workshops and electrical storms.

| Color Name | Hex Code | Usage |
| :--- | :--- | :--- |
| **Storm Black** | `#080A0C` | Primary Backgrounds |
| **Black Steel** | `#1A1D21` | Component Surfaces |
| **Electric Cyan** | `#00F0FF` | Primary Accents / Active States |
| **Forged Silver** | `#C0C4CC` | Secondary Text / Borders |
| **Ember Gold** | `#F5B800` | Critical Warnings / Ignition Points |
| **Thunder Blue** | `#1A2B44` | Subtle Background Gradients |

## 3. Logo & Iconography
- **Logo Concept:** A "Power-Ring" formed by a controlled electrical arc.
- **Glyphs:** Wire and circuit patterns. Use sharp angles and clean, high-tech line work.
- **Aesthetic:** "Machine Resurrection." The UI should feel like a diagnostic suite being powered on in a dark hangar.

## 4. Typography
- **Primary:** `Orbitron` or a similar geometric sans-serif for headings (Technical/Industrial).
- **Secondary:** `Inter` or `Roboto Mono` for body and terminal output (Legibility/Precision).

## 5. Prohibited Elements
- **NO** Pokémon-inspired mascots or silhouettes.
- **NO** Nintendo-style or third-party IP references.
- **NO** generic "Phoenix" fire bird graphics (to avoid confusion with legacy branding).
- **NO** overly vibrant "gamer" RGB gradients; stick to the curated Forged Storm palette.

## 6. Tone of Voice
- **Direct:** Concise and technical instructions.
- **Resilient:** Professional and reassuring in recovery scenarios.
- **Authoritative:** "Truth-First" reporting and clear diagnostic data.
