# ARCWYRE Brand Identity

**Tagline:** Boot the broken. Rewire the future.

## 1. Core Philosophy
ARCWYRE is a **repair-first, recovery-first** platform. It is designed for the moment when a machine fails and the user must reclaim control. The aesthetic is industrial, electric, and resilient.

## 2. Visual Palette: "The Forged Storm"
The brand uses a high-contrast, atmospheric palette inspired by industrial workshops and electrical storms.

## 3. Component Styling Rules
- **Panels & Cards:** Use `--arc-surface` with a 1px border of `--arc-border`. Add a subtle glow of `rgba(49, 215, 255, 0.05)` on hover.
- **Buttons:**
    - *Primary:* `--arc-gradient-arc` (Cyan to Blue) with `--arc-bg` text.
    - *Secondary:* Transparent with `--arc-cyan` border and text.
- **Typography:**
    - Headings: Technical, high-contrast using `--arc-cyan`.
    - Body: High legibility using `--arc-silver` at 80% opacity.
- **Charts & Progress:** Use `--arc-cyan` for active progress and `--arc-ember` for warning thresholds.

## 4. Logo & Iconography
- **Logo Concept:** A "Power-Ring" formed by a controlled electrical arc.
- **Glyphs:** Wire and circuit patterns. Use sharp angles and clean, high-tech line work.
- **Aesthetic:** "Machine Resurrection." The UI should feel like a diagnostic suite being powered on in a dark hangar.

## 5. Prohibited Elements
- **NO** Pokémon-inspired mascots or silhouettes.
- **NO** Nintendo-style or third-party IP references.
- **NO** generic "Phoenix" fire bird graphics.
- **NO** unlicensed mascot designs.

## 6. System Environment (ARCWYRE OS)
- **Boot Splash:** Central Power-Ring logo with an animating electric arc filling the progress circle.
- **Wallpaper:** "Deep Thunder" - Minimalist dark steel texture with a single diagonal cyan arc.
- **Icons:** Outlined, high-stroke icons using `--arc-silver`.
