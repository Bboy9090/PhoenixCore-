main.py\n```\n\nServer runs on `http://localhost:8000`\n\n### API Documentation\n\n- **Interactive Docs:** http://localhost:8000/docs\n- **ReDoc:** http://localhost:8000/redoc\n\n### Core Endpoints\n\n#### Health & Info\n- `GET /api/health` - Server health status\n- `GET /` - Root endpoint\n\n#### Device Management\n- `GET /api/devices` - List all USB/removable devices\n- `GET /api/devices/{device_id}` - Get device details\n- `POST /api/devices/refresh` - Force device scan\n\n#### Hardware Profiling\n- `GET /api/hardware` - Get system hardware profile\n- `GET /api/hardware/profiles` - List known hardware profiles\n\n#### System Monitoring\n- `GET /api/system/metrics` - Real-time CPU, memory, disk metrics\n- `GET /api/system/info` - System information\n- `GET /api/system/usb-activity` - USB device activity\n\n#### USB Creation\n- `GET /api/recipes` - List build recipes (OS types)\n- `GET /api/recipes/{recipe_id}` - Get recipe details\n- `POST /api/safety-check` - Validate device before build\n- `POST /api/build/start` - Start USB build job\n- `GET /api/build/{job_id}/progress` - Get build progress\n- `POST /api/build/{job_id}/cancel` - Cancel build\n- `GET /api/build/jobs/list` - List all jobs\n\n#### OS Images\n- `GET /api/images` - List available OS images\n- `GET /api/images/{image_id}` - Get image details\n\n#### OCLP (macOS Legacy Patcher)\n- `GET /api/oclp/models` - List OCLP-compatible Mac models\n- `GET /api/oclp/check/{model}` - Check model compatibility\n- `GET /api/oclp/macos-versions` - Supported macOS versions\n- `GET /api/oclp/detect` - Detect current Mac model\n\n#### Workflows\n- `GET /api/workflows` - List workflow templates\n- `POST /api/workflows/run` - Execute a workflow\n\n#### Diagnostics\n- `GET /api/diagnostics` - Run system diagnostics\n\n---\n\n## 📱 Mobile App (React Native/Expo)\n\n### Building the Mobile App\n\n```bash\ncd /home/ubuntu/phoenix-core-mobile\nnpm install\nnpm requirements.txt\n\n# Check port 8000 is available\nlsof -i :8000\n```\n\n### Mobile App Can't Connect\n1. Ensure backend is running: `curl http://localhost:8000/api/health`\n2. Check backend URL in Settings (should match your server)\n3. Ensure mobile device is on same network\n4. Try `http://host.docker.internal:8000` if using Docker\n\n### Device Not Detected\n1. Check device is connected: `lsblk` or `diskutil list`\n2. Verify device permissions: `sudo ls -la /dev/sd*`\n3. Try refreshing device list in app\n\n---\n\n## 📚 Documentation\n\n- **API Docs:** http://localhost:8000/docs (Swagger UI)\n- **ReDoc:** http://localhost:8000/redoc\n- **Source Code:** Well-commented
