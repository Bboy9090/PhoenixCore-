# Phoenix Control Center

Phoenix Control Center is the future primary desktop shell for Phoenix OS.

Canonical direction:

- Tauri desktop shell.
- React, TypeScript, and Tailwind UI.
- Rust system APIs for privileged or safety-sensitive operations.
- Phoenix Agent bridge for system state, diagnostics, updates, recovery, and workflow execution.

This app should serve daily-driver workflows first: system health, app setup, creator and gaming readiness, device status, updates, recovery entrypoints, and BootForge integration.
