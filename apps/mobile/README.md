# Phoenix Mobile

Phoenix Mobile is the canonical home for the Expo React Native companion app.

Future responsibilities:

- Companion monitoring and guided repair workflows.
- Device inventory and status views.
- Remote-friendly BootForge and Phoenix Agent interactions.
- Creator, streamer, student, and repair-tech companion experiences.

Generated native Expo payloads must not be committed. Android and iOS native folders should be regenerated through the approved build flow unless a future PR intentionally adopts a bare/native workflow.

No source is migrated here in PR 3.
